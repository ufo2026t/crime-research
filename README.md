# 事件ファイル ― インタラクティブ推理ストーリー

手がかりを集め、真相を再構築し、犯人を突き止める Web 版インタラクティブ推理ストーリーです。
ビルド不要の静的サイトなので、ブラウザだけで遊べます。

## 収録している事件

| ファイル | 事件 | 舞台 |
| --- | --- | --- |
| FILE 01 | 白鷺館殺人事件 ― 嵐の夜の八人 | 十一月、嵐で孤立した湖畔の洋館 |
| FILE 02 | 雪椿亭殺人事件 ― 吹雪の夜の八人 | 一月、雪崩で道を断たれた温泉旅館 |

どちらの事件も主な登場人物は八人で、次の四つの章で進みます。

1. **第一章「来歴」**：八人の生い立ちを読みます。太字の記述と思い出の品を手がかりに、八つの「人物の謎」を解きます。
2. **第二章「幕前」**：事件当日の一日を、八人それぞれの視点で読みます。
3. **第三章（捜査）**：現場を調べ、証言を集め、証拠を突きつけて嘘を暴きます。
4. **終章「推理」**：集めた証拠で真相を再構築し、犯人を指名します。

## 遊び方

`index.html` をブラウザで開き、挑む事件を選んでください。
ローカルサーバーで動かす場合は、たとえば次のコマンドを使います。

```sh
npx serve .
# または
python -m http.server 8000
```

進み具合は、ブラウザの localStorage に事件ごとに自動で保存されます。

## 主な機能

- 固有名詞のふりがな（すべて／初出のみ／なし を切り替え）
- 人物の謎・最終推理の途中経過の保存と再開
- 雨・雪の演出と環境音（Web Audio）
- スマートフォン表示への対応

## ファイル構成

```text
index.html            事件の選択ページ
game.html             ゲーム画面（?s=事件ID で事件を切り替える）
favicon.svg           サイトアイコン
css/style.css         スタイル
js/series.js          事件の登録簿（タイトル、データファイル、ふりがな、建物の絵など）
js/engine.js          ゲームエンジン（全事件で共通）
js/ruby.js            ふりがなの表示
js/series/<事件ID>/
  data.js             人物・手がかり・調査場所・会話・推理
  past.js             第一章「来歴」と人物の謎
  stories.js          第二章「幕前」
```

## 事件を追加するには

1. `js/series/<新しい事件ID>/` に `data.js`・`past.js`・`stories.js` を作ります（既存の事件と同じ形式）。
2. `js/series.js` の `window.SERIES` に、`id`・`saveKey`・`files`・`ruby` などを登録します。

選択ページに事件のカードが自動で追加され、`game.html?s=<新しい事件ID>` で遊べるようになります。
